## 1.1.34.0 重大修复与更新

本次汇总此前数轮修复，应用名称统一为“即影”。重点解决下载不完整、字幕编辑繁琐、导航动效割裂和引擎初始化等待问题。

- **下载完整性与格式**：不再静默跳过失败的视频分片，完成前检查实际画面时长、文件字节数和容器；修复部分视频下载不全、格式与扩展名不一致的问题。
- **字幕编辑**：原文与译文逐条对照，点文字即可修改，序号和时间轴保留；保存后可复用原片重新生成视频。
- **识别与翻译**：补充漏句、漏译、空译文及双语覆盖检查，结合视频上下文与术语约束处理翻译；已有字幕和任务仍可继续使用。识别与翻译结果仍需人工校对。
- **平台解析与扫码**：增强抖音、小红书分享链接、嵌入链接和多画质解析，保留完整分享参数；扫码后自动继续原链接，普通设置保存不覆盖登录状态。
- **设置与外观**：保留原磨砂材质和设置页面宽度，移除冗余横线及高级Cookie登录入口，低频选项默认折叠。
- **平滑导航与封面**：蓝色选中框和底板一起滑动，重复点击不再截断轨迹；页面立即可操作，解析结果与封面异步解码后平滑渐入。
- **启动与占用**：翻译、二维码和图片库延后到实际使用时加载，背景与字体按需准备；确认引擎目录后及时连接，减少等待其他端口的时间。
- **通知与解析引擎更新**：下载完成支持Windows系统通知；解析引擎跟随yt-dlp官方GitHub发布，验证下载完整性，在解析、传输空闲后安全切换。

详细构建与验证范围见[开发说明](开发说明.md)和[源码验证](源码验证.md)。GitHub版本标签与微软商店审核、上架分别推进，商店可用版本以商店页面为准。

## 为什么选择即影

- **下载与字幕一起完成**：在同一个工具中下载视频、识别语音、翻译字幕，并导出字幕文件或带字幕的视频。
- **画质选择清楚**：解析后选择网站实际提供的分辨率和格式，按需要保存视频。
- **本地识别保护隐私**：使用本地语音模型时，音频识别在你的设备上完成；云端识别和翻译由你主动选择与配置。
- **功能按需使用**：只下载视频时无需语音模型，也无需等待字幕处理；需要本地识别时再下载模型。
- **任务方便管理**：查看下载进度，取消、重试或恢复未完成任务，方便继续之前的下载。
- **商店安装省心**：通过 Microsoft Store 获取带商店签名的安装版本，并接收后续更新。

## 下载与安装

推荐通过 **[Microsoft Store 安装即影](https://apps.microsoft.com/detail/9N2XR4X7CXPR)**，获取商店签名的安装版本和后续更新。

系统要求：Windows 10 2004 或更新版本 / Windows 11，x64。

[GitHub Releases](https://github.com/Links2008/Jiying/releases) 提供独立的版本记录和历史下载。两个渠道的版本可能不同，请以各自页面为准。便携版请下载 ZIP，完整解压后运行 `Jiying.Native.exe`；MSIX 的安装条件请查看对应版本说明。

## 三步开始

1. **粘贴链接**：打开即影，粘贴具体视频的链接并解析。
2. **选择下载内容**：选择可用画质、格式和保存位置。
3. **按需生成字幕**：选择原语言字幕或翻译字幕，再开始任务；只需要视频时，可关闭字幕处理。

可选画质取决于原视频和网站提供的资源。需要登录的视频，也需要你拥有对应的访问权限。

## 能做什么

| 功能 | 使用方式 |
| --- | --- |
| 视频下载 | 解析链接，选择网站实际提供的分辨率和格式 |
| 任务管理 | 查看进度，取消、重试，并恢复未完成任务 |
| 本地字幕识别 | 使用 Whisper 语音模型，在设备上处理音频 |
| 云端识别 | 在设置中配置所选服务及其接口 |
| 多语言翻译 | 配置翻译服务，将识别后的字幕转换为目标语言 |
| 字幕输出 | 保存字幕文件，或将字幕烧录到视频中 |

本地识别需要先下载语音模型；首次使用时按提示准备即可。只下载视频时不需要语音模型。云端识别和翻译需要你配置对应服务，服务的可用性和费用由其提供商决定。

## 常见问题

**解析失败或没有期望的画质？**  
确认链接指向具体视频且仍可访问，再检查网站是否要求登录。原视频的清晰度、账号权限和网站限制都会影响可下载资源。反馈时请附软件版本、平台、错误提示和可公开的示例链接。

**GitHub 的 MSIX 无法安装？**  
历史发布中的 MSIX 可能未使用受信任证书签名，请先查看该版本说明。推荐直接从 [Microsoft Store](https://apps.microsoft.com/detail/9N2XR4X7CXPR) 安装。

**字幕识别不准确？**  
音频质量、语言选择和语音模型会影响结果。可检查识别语言、尝试更合适的模型，或修改导出的字幕文件。自动识别与翻译结果仍需人工校对。

## 隐私与支持

设置、任务记录、下载文件和本地识别数据保存在你的设备上。解析和下载会访问对应视频网站；主动使用云端识别或翻译时，相关音频或字幕会发送给你配置的服务商。
