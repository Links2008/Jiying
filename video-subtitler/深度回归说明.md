# 识别与字幕流水线深度回归

首轮修复集中在内容完整性、异常恢复、取消和语言字段处理。测试全部使用隔离
临时数据、现场生成的音频或模拟服务回复，没有读取用户配置、任务或媒体。

| 触发条件 | 原行为 | 修复后的行为 |
| --- | --- | --- |
| 云端只给部分段落，或尾句时间戳损坏、为 NaN/无穷大 | 丢尾句，或将坏时间轴写入字幕 | 有完整文本时保留全文，以有效音频时长恢复；不编造一秒时长 |
| 云端返回 english、Chinese、地区码，或未回语言但请求指定了源语言 | 生成错误语言轨，重复进行同语言翻译 | 归一常见语言全名和地区码；缺少检测结果时复用已指定语言 |
| 翻译服务返回空 choices、错误结构或空 content | 原始异常绕过既有重试 | 按现有最多三次重试处理；持续异常明确报错，不写完成检查点 |
| 最终识别缓存损坏、为空、含无效文本或不可显示的时间轴 | 每次重试继续使用坏缓存并失败 | 隔离坏缓存，复用有效分段结果恢复；保留诊断副本直至删除任务 |
| 长视频每段首词经原文对齐去掉前置空格 | 英文词在接缝处黏连 | 全局重建时补回词间空格，重新对齐词表；中文不插入多余空格 |
| 任务等待繁忙的下载或 FFmpeg 资源池 | 取消仍等待其他任务结束 | 等待期间每 0.2 秒检查取消，未取得名额时不会多释放名额 |
| 源或目标语言字段带路径分隔符 | 字幕文件名可能被当作目录 | 提交前校验语言；生成文件时再次校验，保留合法语言与地区代码 |
| 桌面保存多 GB 视频 | 整部视频先读进字节数组，受缓冲上限与内存限制 | 以 64 KiB 缓冲流式写临时稿，完整成功后替换；取消、截断或错误保留旧文件 |

## 执行回归

```bash
cd video-subtitler
JIYING_TEST_FFMPEG=/实际路径/ffmpeg .venv/bin/python -m pytest tests -q -rs
```

`tests/test_deep_pipeline_regressions.py` 覆盖这轮修复，包括损坏最终缓存恢复时不再
调用已完成分段的识别器、异常响应重试后成功及持续异常失败、资源池尚未释放时
取消完成、取消时不额外释放资源，以及不合法语言在网络探测前被拒绝。
既有字幕回归会真实封装 MP4 并提取嵌入字幕，还会解码烧录结果检查文字可见性。

桌面客户端的文件传输回归不需要 WPF 或 WebView2，在仓库根目录使用 .NET 10：

```bash
dotnet run --project mistdown/native-shell/tests/EngineArtifactRegression/EngineArtifactRegression.csproj -c Release
```

它编译实际 `EngineClient.cs` 和传输模型，在隔离回环 HTTP 中实传 128 MiB 并核对
SHA256，同时检查响应缓冲上限、声明超过 2 GB 的响应取消、截断、HTTP 错误、
分块响应和替换失败后的旧文件保护。超过 2 GB 的用例只发送首块后取消，未完成
整部多 GB 文件的实传验收。分配量统计包含测试服务和客户端，属于累计托管内存
分配，不能当作整个软件的峰值内存。

| 重启遗留任务或产物登记读取失败 | 未完成阶段与下载作业一同中断；重试刷新阶段时间；无法识别用户文件时保留工作目录 |

- 上次重生成的晚到收尾不能解锁新字幕的保存，防止重复写入；晚到错误提示也须对应原字幕。
- 删除操作保存自己的任务快照，不能失效错误任务的缓存、关闭新确认框或解锁新一次删除。

- 非对象 JSON 探测回复不再中断整个端口发现；失效的在途探测不能宣称连接成功。
- 旧 API、预览、视频传输或事件监听的晚到失败只影响原连接代际，同端口重连也受保护。

接缝出现不同措辞时保守保留两边可能造成重复，实际模型听写质量仍需逐字稿评测。
模型释放测试使用模拟对象，不代表已测量真实 GPU 内存回收或原生解码阻塞取消。
普通无偏移 SRT 仍采用 FFmpeg 原生标记解析；偏移 ASS 字面量测试不代表所有字幕
格式或排版命令均已统一。SQLite 并发结果来自本机 Python/SQLite 版本，不能当作所有
平台的故障发生率。
本轮没有原生 Windows 完整界面验证，没有提交、合并、创建 PR、打包或发布。
