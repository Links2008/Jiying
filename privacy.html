即影隐私政策

更新日期：2026 年 9 月 15 日

即影是一款在你的 Windows 设备上运行的视频下载、字幕识别与翻译工具。Linkshub 不销售用户数据，也不在应用中投放广告或使用分析追踪服务。

本地数据

应用会在设备上保存设置、任务记录、下载文件，以及你主动配置的 API 密钥、Cookie 来源和文件路径。你可以通过删除应用数据或卸载应用清除这些信息。

网络传输

分析或下载链接时，应用会连接你指定的视频网站或媒体地址。使用本地字幕识别时，媒体处理在设备上完成。只有当你主动选择云端识别或翻译服务时，音频、字幕文本和相关请求才会直接发送给你选择的第三方服务商；其处理受对应服务商隐私政策约束。

你的选择

你可以不配置云端 API 或 Cookie，并使用本地识别功能。请只处理你有权访问和下载的内容。

联系与许可

如有隐私或支持问题，请通过 GitHub Issues 联系发布者。本软件依照 MIT License 授权。
