# 客户端引擎与编辑回归

两套回归均使用临时数据、假凭据和隔离服务，不读取用户配置，不启动产品引擎，不调用识别或翻译供应商。

## 可在 Linux 或 Windows 运行的回环回归

```sh
dotnet run --project mistdown/native-shell/tests/EngineArtifactRegression/EngineArtifactRegression.csproj -c Release
```

使用实际 `EngineClient.cs` 和回环 HTTP，验证 128 MiB 视频内容、流式内存边界、响应缓冲上限、超过 2 GB 的响应取消、失败时保留旧文件及临时稿清理。还验证错误事件流响应体可取消，以及缺失、异常或未知任务状态不会被误认为旧引擎可以退出；测试不会退出任何真实进程。

## WPF 异步编辑回归

在 Windows 与 .NET 10 SDK 下运行：

```powershell
dotnet run --project .\mistdown\native-shell\tests\EngineArtifactRegression\DesktopRaceRegression\DesktopRaceRegression.csproj -c Release
```

打开实际 `MainWindow`，解除自动引擎连接，并注入可控的 HTTP 处理器。验证连续点击字幕的晚到响应不能替换新字幕或保存对象、打开其他对话框或关闭后不能被旧请求重新打开，以及设置保存期间新输入的假凭据保留且显示尚未保存。已提交且未继续修改的假凭据会从输入框清除。

还验证字幕保存与在途任务详情请求交错时，旧详情不能重新长期填入缓存；刷新执行期间的新通知会合并保留，随后同步最新任务与产物。未保存字幕关闭、切换对话框或主窗口退出时使用默认保留的确认；测试只回复本测试窗口所属的原生确认框，检查拒绝丢弃、保存后关闭和显式丢弃均符合用户选择，且不会覆盖已保存内容。

既有 `UiRegression` 可用 `JIYING_SUBTITLE_WORKFLOW_ONLY=1` 单独运行字幕入口、编辑、保存失败、提交失败和重生成队列的原有断言，默认完整流程不变。显式专项在 Wine 下只给测试宿主添加中文字体回退；完整流程的扫码前置仍受 Wine 字体支持限制，不能据此宣称完整界面通过。

后续专项还覆盖旧重生成刷新收尾不能解锁另一字幕的在途保存；旧删除完成不能关闭或解锁新的确认弹窗，也不能失效错误任务的缓存。批量清理发送弹窗确认时的 `task_ids` 快照，随后完成的其他任务保留。客户端连接版本保护旧探测、旧请求和旧事件监听的晚到结果，不同端口与同端口重连均覆盖；事件循环可用 `JIYING_EVENT_CONNECTION_ONLY=1` 单独验证。

连接回环回归还验证其他本机服务返回合法的非对象 JSON 时不会中断引擎发现，以及 API、字幕预览、视频传输三类请求的当前失败会断开对应连接、旧失败会保留后来连接。WPF 专项真实运行窗口与事件循环，用暂停响应触发重复保存、重复删除、错关新弹窗和批量范围扩大的旧行为，再验证保护；确认目标与按钮解锁均绑定相应操作和弹窗。批量接口显式空 `task_ids` 不删除任务，缺省或 `null` 保留旧的全终态清理兼容行为；桌面确认路径始终发送快照列表。

这些专项没有调用真实识别或翻译服务。WPF 请求和事件重连使用可控 HTTP 处理器，验证应用的异步衔接；便携回环用例实际传输数据，但不能代替 Windows 上的真实引擎重启、网络中断、文件占用、完整界面或用户实际媒体验收。测试故障期间仅清理隔离编辑对象，产品的未保存确认仍保留。

Linux 可以加 `-p:EnableWindowsTargeting=true` 交叉构建，但不能用构建通过代替运行验证。Wine 上的专项运行仅作为补充，测试宿主使用现有中文字体回退；原生 Windows 的字体、WebView2、完整界面和端到端流水线仍需独立验证。

持续开发时请使用 `--artifacts-path` 将产物放在仓库之外；本轮未提交、打包或发布。
