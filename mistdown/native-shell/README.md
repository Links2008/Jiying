# 即影原生桌面版

1.1.28.0 优化小红书和抖音扫码加载：扫码窗口先打开，不等待本地视频引擎；扫码阶段暂停网页视频及无关封面，二维码与安全验证照常加载。小红书过期二维码优先使用官网刷新控件，减少整页重载；首屏未就绪时最多自动重试一次，已有二维码或安全验证时不重载。抖音先显示紧凑的官网扫码窗口，手机确认后自动继续具体视频或分享链接；推荐首页登录后展开官网选择视频。继续使用系统 WebView2，不增加依赖。

1.1.27.0 将小红书连接简化为扫码登录：展示紧凑的官网二维码，手机确认后自动保存登录状态并重新解析原链接，不再要求选择视频或点击确认；访客会话不会被误认为登录成功。二维码可刷新，保存失败可重试；复用系统 WebView2，不增加浏览器内核和 Python 依赖。

1.1.26.0 修复无线程的残留客户端记录阻塞引擎切换，未连接时显示具体重试提示；有窗口或任务的旧引擎仍受保护。清空网址会取消过期解析并恢复初始居中页面，解析与返回都有过渡。设置分组增加高度、淡入淡出与箭头动效，连续点击后仍能完整展开，收起时将键盘焦点移回标题。字幕支持本机已安装字体与中文、英文名称筛选，继续保留内置思源黑体，无需随包新增字体。

设置仍为单页“常用、语音与翻译、高级”，低频选项默认折叠，显示配置摘要与明确的保存结果；云端参数仅在启用对应服务时显示。D 盘可用时默认下载到 `D:\即影\Downloads`，保留其他自定义目录；无 D 盘时回退到用户视频目录。已有下载文件不移动。

NVIDIA 语音加速库和 Whisper 模型仍按需下载，已有缓存继续使用。

小红书保留上游提供的原始流，未知分辨率明确标注；竖屏画质显示真实宽高。两站连接只需扫码并在手机确认，具体链接登录后自动继续。抖音支持具体视频链接、分享短链接和分享文字，公开分享页作为备用解析路径；推荐首页登录后会打开官网选择窗口，请打开具体视频并点击“使用此视频”。各平台独立保存，解析与下载共用。实际可下载清晰度取决于平台返回的源流。

保留 1.1.16.0 的 Anime 移除及中文漏句修复：所选画质不会静默降级，翻译严格校验编号与非空内容，双语字幕保持两种语言完整覆盖；无效旧字幕在成功补译后保留备份。

WPF 客户端保留原生界面、动效和版画背景，直接连接 `JiyingEngine.exe`。官网连接窗口复用系统 WebView2 Runtime，安装包仅包含 SDK 加载器，不捆绑浏览器内核；缺少系统运行时的电脑需安装或修复 WebView2 后再扫码，抖音和 B 站也保留浏览器或 Cookie 文件连接。已完成任务可编辑字幕并重新生成视频。

## 运行

请先等旧版任务结束并关闭旧版即影。解压完整目录后双击 `Jiying.Native.exe`，不要直接在压缩包预览中运行。请保留相邻的 `engine/` 目录；程序只连接这份引擎，未运行时会自动启动。关闭界面不会中断下载任务。

ZIP 是解压运行版本，MSIX 是安装包；侧载 MSIX 需要系统信任其签名。已有下载文件不会自动整理。

## 已覆盖界面

- 解析：链接探测、画质格式、字幕语言、本地/云端识别、LLM 翻译、硬字幕样式、输出目录与预览。
- 传输队列：任务阶段、实时进度、断线轮询恢复与取消。
- 已完成：简洁状态、失败重试、打开目录与删除确认。识别字幕的源片与 SRT 留在引擎工作目录，下载目录只放最终视频。
- 设置：下载、模型、识别/翻译凭证、网络、Cookie、主题、强调色、背景浓度和解析引擎更新。
- 公共状态：空态、加载、成功、失败、未知状态、连接错误、通知、目录选择及二次启动激活。

## 构建

```powershell
dotnet build .\Jiying.Desktop\Jiying.Desktop.csproj -c Release
dotnet run --project .\Jiying.Desktop\Jiying.Desktop.csproj -c Release -- --self-test
dotnet publish .\Jiying.Desktop\Jiying.Desktop.csproj -c Release -r win-x64 --self-contained true
```
